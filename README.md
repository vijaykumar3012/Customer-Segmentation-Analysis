# Customer-Segmentation-Analysis

📊 **SQL + RFM Customer Segmentation Project**

Today, I worked on a **Customer Segmentation analysis using SQL** and implemented the **RFM (Recency, Frequency, Monetary) model** to understand customer behavior.

🔹 **Recency (R):** How recently did the customer purchase?
🔹 **Frequency (F):** How frequently does the customer purchase?
🔹 **Monetary (M):** How much does the customer spend?

Using SQL, I calculated:
✅ RFM scores
✅ RFM Total Score
✅ Customer Segments such as **Champions, Loyal, and At Risk**
✅ Customer purchase behavior and transaction patterns

This project helped me strengthen my skills in **CTEs, aggregate functions, date functions, joins, CASE statements, and window functions**.

💡 **Key takeaway:** SQL is not just about retrieving data—it can be used to transform raw transaction data into meaningful business insights.
